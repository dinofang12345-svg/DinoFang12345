桌面壁纸专区

一期产品交互与规则说明

1. 功能入口与登录

  • 专区入口位于 APP 首页，由运营配置曝光。
  • 用户点击入口时必须先完成登录，不允许游客浏览或下载。
  • 登录成功后自动进入壁纸专区；登录取消或失败则停留在当前页面。
  • 服务端频道、列表、详情和下载接口必须再次验证登录态，不得仅依赖客户端状态。

2. 首页浏览

  • 一级分类固定为"静态 / 动态"，首次进入默认选中"静态"。
  • 频道 Tab 按后台 sort_order 升序展示，"全部"固定在首位。
  • 频道名称完全由后台配置，客户端不得写死。
  • 默认选中"全部"频道；切换类型后重置为"全部"。
  • 原频道在新类型中不存在时，自动回退到"全部"。
  • 频道启用且当前类型下至少有一张有效已发布壁纸时才展示。
  • 一张壁纸只能绑定一个频道，且只能是静态或动态其中一种类型。

3. Android 流程

静态壁纸

  1. 下载图片 → 校验版本/大小/哈希 → 写入本地索引。
  2. 通过 WallpaperManager 设置桌面，一期不提供锁屏或同时设置选项。

动态壁纸

  1. 下载 H.264 MP4 → 校验 → 写入本地索引 → 启动 WallpaperService。
  2. 本地循环播放 MP4，屏幕关闭或壁纸不可见时暂停解码以节省资源。
  3. 服务启动、解码或系统确认失败时，不得向用户报告成功。
Android 下载完成按钮：已下载，设置为桌面。一期静态和动态均只支持桌面，不支持锁屏。

4. iOS 静态壁纸

  1. 用户点击保存图片。
  2. 首次保存前申请照片添加权限。
  3. 下载并校验图片，保存至系统相册。
  4. 提示用户前往"设置 → 墙纸"手动应用。
完成状态必须描述为"已保存到相册"，不得描述为"已设置壁纸"。

5. iOS 动态壁纸

  1. 服务端预生成约 3 秒 Live Photo 配对资源（一张静态封面图 + 一段配对视频）。
  2. 用户点击"下载并生成实况壁纸"。
  3. 首次执行时展示权限用途说明并请求相册权限。
  4. 下载配对资源并校验，展示"正在下载实况壁纸资源"和"正在保存实况壁纸到相册"进度。
  5. 使用 Photos 框架将图片和 paired video 写入系统相册。
  6. 用户手动进入"设置 → 墙纸"完成应用。
APP 不得承诺直接设置系统墙纸，也不得把相册保存记为设置成功。动态效果仅支持锁屏。

6. 已下载页面

  • 数据以本机真实存在且校验有效的文件为准，不以服务端记录为准。
  • 只保留"静态 / 动态"Tab，不增加频道筛选，不展示红点或数字角标。
  • 本地文件缺失、损坏或服务端版本更新后，提示重新下载，不展示为可用状态。
  • 线上壁纸下架后，本地有效文件可保留使用，但禁止发起新的下载。

7. 下载状态与完整性校验

  • 下载状态机：未下载 → 下载中 → 校验中 → 已下载 / 失败可重试；下载中禁止重复创建任务。
  • 下载完成前必须校验文件大小、壁纸 ID、资源版本和服务端提供的哈希值。
  • 校验失败立即删除临时文件，不写入已下载索引。
  • 本地索引记录壁纸 ID、类型、资源版本、本地路径、校验值和下载时间。

8. 动态视频规范

  • 后台上传动态视频时长必须小于等于 5 秒，竖屏，帧率建议 24~30fps。
  • 分辨率建议 1080×1920，不包含需要播放的音频。
  • 服务端输出：Android 为 H.264 MP4（循环播放），iOS 为统一约 3 秒 Live Photo 配对资源。

9. 后台内容规则

  • 后台导航仅包含"频道管理 / 壁纸列表 / 交互说明"三项。
  • 频道管理：列表展示频道名称、排序、各类型壁纸数量、有效时间和状态；"新增频道"弹窗配置频道名称与生效时间（上线/下线时间），新增和编辑共用弹窗；频道启停通过修改有效时间控制，不设独立停用按钮。
  • 壁纸列表：展示全部已配置壁纸，支持类型、频道、发布状态、资源状态和名称筛选，支持分页；列表包含"使用人数"列（服务端按下载按钮点击 UV 去重统计）；"添加壁纸"按钮打开新增/编辑共用弹窗；操作列为编辑和删除（资源失败时额外提供重试）；不设独立上线/下线按钮，上下线通过修改生效时间控制。
  • 频道和单张壁纸均支持通过生效时间控制上下线，频道支持人工排序。
  • 动态视频上传时长必须小于等于 5 秒。
  • 动态壁纸保存后进入资源处理中；Android MP4 与 iOS Live Photo 双端资源全部成功后，按生效时间自动发布；资源就绪前发布状态为"待上线"。
  • 从未发布的壁纸可物理删除；已发布壁纸可直接软删除。

10. 异常处理要点

  • 未登录、登录取消和令牌失效时，不得返回受保护内容。
  • 频道或壁纸已下线时，停止浏览和下载，不主动删除用户本地文件。
  • 平台资源生成中或失败时，仅向资源可用平台返回内容。
  • 网络中断、下载地址过期、存储空间不足时给出明确提示并允许重试。
  • 文件损坏或版本过旧时，清理无效文件并提示重新下载。
  • Android 设置取消或 WallpaperService 失败时，不得报告成功。
  • iOS 相册权限拒绝或受限时，不得写入，并引导用户前往系统设置开启。
  • 后台保存校验失败时，一次性展示所有阻塞原因。

11. 一期不包含

  • 游客浏览或下载。
  • 用户上传、AI 生成、收藏和社区分享。
  • Android 锁屏壁纸或桌面/锁屏选择。
  • iOS 直接设置系统墙纸。
  • 已下载跨设备同步。
  • 正式 APP 中的 Android/iOS 手动切换（仅评审 Demo 提供切换演示）。
